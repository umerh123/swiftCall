# SwiftCall Dialer — Android app

React Native (bare, Android target) client for the `webapp/` PHP backend. Uses
Telnyx's `@telnyx/react-voice-commons-sdk` for VoIP calling with a real
incoming-call screen, ringtone, and wake-from-killed via Firebase push.

See **[../MOBILE_SETUP.md](../MOBILE_SETUP.md)** for the full setup guide
(Firebase project, Telnyx push credential, building, and installing).

Quick reference once setup is done:

```
npm install
npx react-native run-android
```
